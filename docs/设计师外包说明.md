# 照片地理定位器 — 前端设计外包说明

**目标**：仅优化前端 UI/UX 视觉设计，不动任何功能代码（JS/JSX 逻辑）。

**技术栈**：React + Tailwind CSS + MUI (Material UI) + Leaflet + 自定义 CSS  
**唯一需修改的文件**：`src/index.css`  
**参考工具**：GeoSetter（见下方截图）

## 4. 设计约束（重要）

### 4.1 ❌ 不能做的事
- **不能改任何 .jsx 文件**（JSX 结构和交互逻辑必须保持）
- **不能改 Tailwind class 名称**（组件通过 class 名控制显示隐藏和布局）
- **不能删改现有的 CSS class 名称**（组件通过 ID/class 绑定交互）
- **不能改 Leaflet 的 .leaflet-xxx class**

### 4.2 ✅ 可以做的事
- **修改 `src/index.css` 中任何属性的值**（颜色、尺寸、圆角、阴影、动画等）
- **添加新的 CSS 规则**（如新动画、hover 效果、过渡）
- **调整字体大小、行高、间距**
- **优化黑暗模式或增加新的配色方案**
- **改进 Leaflet popup 的视觉样式**

### 4.3 技术注意
- 项目同时使用 Tailwind CSS 和自定义 CSS，Tailwind 的优先级可能高于自定义 CSS，需要时用 `!important` 或提高选择器优先级
- MUI 组件（Button、Chip、TextField 等）的样式由 MUI 主题控制，可通过 `sx` prop 覆盖
- Leaflet 的地图和标记由 JS 动态创建，CSS 通过 class 名控制

## 5. 建议优化的方向

1. **整体色调统一**：目前暗色工具栏 + 浅色内容区，可以考虑深色/浅色双模式
2. **照片列表卡片**：缩略图、文件名、坐标的排版层次感
3. **图像预览区**：工具栏位置、缩放控件样式、底部信息栏布局
4. **地图标记点**：水滴形状、颜色区分（DJI 航拍 vs 手机照片 vs 手动定位）
5. **Popup 弹窗**：照片缩略图与文字信息的比例、阴影层次
6. **拖拽条**：视觉引导更明显（如中间三个点 dots icon）
7. **空状态页面**：WelcomeOverlay 和空预览区的引导设计
8. **进度条 / 状态栏**：加载动画、统计数字的呈现方式
